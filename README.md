# Design Request

Конструктор технических заданий для дизайн-команды (Design WL).

Рабочий сайт после настройки GitHub Pages: https://komissarsaroka.github.io/design-request/

## Публикация

В GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Статический сайт находится в `index.html`. Он не зависит от проекта `health-diary`.

## Возможности

1. Клиент, Slot Name, брендбук, логотип и Adult.
2. Creative Type; Segment для GIF.
3. GEO, тексты и живой предпросмотр баннера.
4. Идея дизайна, анимация, референсы, REDCOREST.
5. Технические требования к AdTarget, Kadam, Retarro и Meta.
6. Финальная сводка и экспорт JSON.

Черновики хранятся локально в браузере. Файлы не отправляются на сервер. Интеграция с Jira пока не подключена.
